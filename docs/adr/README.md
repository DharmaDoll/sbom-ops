# Architecture Decision Records

This directory records architecture decisions that materially affect security,
operations, infrastructure, or long-term project direction.

ADR status values:

- `Proposed`: written, not yet validated or adopted
- `Accepted`: adopted as the current project direction
- `Superseded`: replaced by a later ADR

Infrastructure ADRs must include:

- decision context
- considered options
- security and operational consequences
- rollback path
- validation plan
- references to relevant official documentation
